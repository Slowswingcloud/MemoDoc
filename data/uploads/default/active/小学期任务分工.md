## 4. 每日固定任务

每个实践日均执行以下任务：

1. 范文歆维护任务看板，记录负责人、计划完成时间、验收条件和证据链接。
2. 全员提交“已完成、今日计划、当前阻塞”三项信息；胡思琪线上提交。
3. 每项代码任务通过独立分支和 Pull Request 提交，由至少一名非作者检查。
4. 每位负责人在当天结束前附上提交、测试日志、文档或配置文件链接。
5. 范文歆汇总当日阻塞；影响第二天工作的阻塞必须当天确定负责人和处理方案。
